# 스페이스 크루 : 배신자를 찾아라 (3차 버전)

학급 전체(최대 40명)가 함께하는 실시간 추리 웹게임입니다.
대원은 우주선 곳곳의 미니게임 미션을 끝내고, 배신자는 몰래 대원을 제거합니다.
선생님은 관전 화면에서 전체 상황을 보며 게임을 관리합니다.

## 파일 구성

```
space-crew/
├─ server.js        게임 서버 (역할, 이동, 제거, 사보타주, 회의, 투표, 기록)
├─ package.json     필요한 라이브러리 목록
├─ render.yaml      Render 배포 설정
└─ public/
   ├─ index.html    화면 구조
   ├─ style.css     디자인
   ├─ game.js       조작, 미니게임, 미니맵, 관전 화면
   ├─ gfx.js        그래픽 (맵 장식, 로봇, 효과)
   ├─ sound.js      효과음 (파일 없이 브라우저에서 생성)
   ├─ screen.html   전자칠판 화면
   ├─ screen.js     전자칠판 화면 동작
   └─ map.js        맵 데이터 (서버와 화면이 함께 사용)
```

## 1. GitHub에 올리기

1. github.com 로그인 → 오른쪽 위 `+` → **New repository** → 이름 `space-crew` → **Create repository**
2. `uploading an existing file` 클릭 → 압축을 푼 `space-crew` 폴더 **안의 내용물 전체**를 끌어다 놓기
   (`server.js`가 저장소 맨 위에 보여야 해요.)
3. **Commit changes**

이미 1차 버전을 올렸다면, 같은 저장소에 새 파일들을 다시 끌어다 놓고 Commit하면 덮어써집니다.

## 2. Render에 배포하기

1. render.com 에 GitHub 계정으로 로그인 → **New +** → **Web Service** → `space-crew` 저장소 선택
2. Runtime **Node**, Build Command `npm install`, Start Command `npm start`, Instance Type **Free**
3. **Environment** 항목에서 환경변수 추가 (중요!)
   - Key: `TEACHER_PASSWORD`
   - Value: 선생님만 아는 비밀번호 (예: `kim2026space`)
4. **Create Web Service** → 몇 분 뒤 `https://space-crew-xxxx.onrender.com` 주소가 생깁니다.

환경변수를 넣지 않으면 기본 비밀번호 `teacher1234`가 쓰이니 꼭 바꿔 주세요.
(이미 배포했다면 Render 서비스 화면 → Environment에서 추가하면 자동으로 다시 시작돼요.)

## 3. 수업에서 진행하기

1. **수업 5분 전**, 선생님이 `https://내주소.onrender.com/?teacher=비밀번호` 로 접속 → **선생님으로 입장**
   (무료 서버는 잠들어 있다가 처음 접속에 30초~1분 걸려요. 비밀번호는 주소창에서 바로 지워져서 화면에 안 보여요.)
2. 학생들은 `https://내주소.onrender.com` 으로 접속해 이름을 입력하고 탑승합니다.
3. 선생님 화면에서 설정과 퀴즈를 정하고 **게임 시작**
4. 게임 중 선생님 화면은 **전체 맵 관전 모드**: 모든 대원 위치, 배신자(빨간 테두리), 미션 진행, 사보타주 상태가 보여요. 전자칠판에는 띄우지 마세요(배신자가 보여요).
5. 회의가 열리면 **토론은 교실에서 말로**, 투표는 각자 화면에서 합니다.
6. 게임이 끝나면 상장과 기록표가 나오고, 선생님이 **대기실로 돌아가기**를 누릅니다.

### 📺 전자칠판 화면
선생님 화면의 **📺 전자칠판 화면 열기** 버튼(또는 `내주소/screen.html`)을 전자칠판에 띄우세요.
- 대기실: 접속 주소와 QR 코드, 탑승한 학생 목록
- 게임 중: 전체 미션 진행도, 사보타주 경고, 공개된 탈락자
- 회의: 사이렌 연출, 남은 시간, 투표한 사람 표시, 추방 장면
- 결과: 상장과 기록표
배신자와 대원 위치는 **전혀 표시되지 않아서** 안심하고 띄워도 돼요. 처음에 "소리 켜고 시작하기"를 누르면 교실 스피커로 효과음이 나와요.

### 선생님 관리 기능
- **내보내기(✕)**: 대기실과 게임 중 모두 가능. 내보낸 학생은 다시 들어올 수 없어요.
- **내보내기 취소**: "내보낸 학생" 목록의 취소 버튼을 누르면 그 학생이 다시 탑승할 수 있어요.
- **게임 강제 종료**: 진행 중인 판을 바로 끝내고 대기실로 돌아가요.
- **이름 필터**: 욕설·비속어 이름과 중복 이름은 입장할 수 없어요. 단어는 `server.js`의 `BAD_WORDS`에서 추가할 수 있어요.

### 퀴즈 미션 넣기
대기실의 **퀴즈 문제 넣기**를 열고 한 줄에 한 문제씩 입력한 뒤 **퀴즈 저장**:

```
엔진의 4행정 중 첫 번째는? | 흡입 | 압축 | 폭발 | 배기 | 1
물의 화학식은? | CO2 | H2O | O2 | NaCl | 2
```

마지막 숫자가 정답 번호예요. 보기는 2~4개. **퀴즈 미션 수**만큼 대원마다 📘 퀴즈 기계가 배정되고,
틀리면 3초 뒤 다른 문제가 나와요. 저장한 퀴즈는 선생님 브라우저에도 기억돼요.

### 게임 규칙
- 대원 승리: 모든 미션 완료 또는 배신자 전원 추방
- 배신자 승리: 살아 있는 배신자 수가 살아 있는 대원 수 이상
- 배신자 능력
  - **제거**(대기시간 있음)
  - **환풍구**: 같은 그룹의 환풍구로 순간이동
  - **사보타주**(35초마다): 💡 불 끄기(대원 시야가 아주 좁아짐, 전기실 ⚡ 패널에서 스위치를 모두 올리면 복구) / 🔒 문 잠그기(고른 방의 문이 12초 동안 잠김)
- 시야는 벽에 가려져요. 벽 너머 대원은 보이지 않아요.
- 오른쪽 위 **미니맵**에는 내 위치와 내 미션 위치만 표시돼요. 누르면(또는 M 키) 크게 볼 수 있어요.
- 문 잠그기는 서버에서도 확인하므로 꼼수로 지나갈 수 없어요.
- 제거된 대원은 유령이 되어 미션을 계속할 수 있어요 (투표는 불가)
- 긴급회의는 한 사람당 한 판에 1번

### 조작
- 이동: 방향키 / WASD, 태블릿은 왼쪽 아래 조이스틱
- 사용(미션·긴급버튼·수리): E 또는 스페이스 / 신고: R / 제거: Q
- 배신자: 환풍구 V, 사보타주 F
- 미니맵 크게 보기: M

### 미니게임 9종
전선 연결, 숫자 순서 누르기, 데이터 업로드, 연료 채우기, 계기판 맞추기, 카드 긁기, 쓰레기 버리기, 운석 부수기, 지식 퀴즈

### 게임 후 기록
미션왕, 명탐정(배신자에게 정답 투표), 신고왕, 최고의 배신자 상장과 전체 기록표가 나와요.

### 그래픽과 소리
- 미니맵 아래 **🔊** 버튼으로 효과음을 켜고 끌 수 있어요.
- **그래픽 높음/낮음** 버튼으로 화질을 바꿀 수 있어요. 기기가 느리면 게임 시작 5초 안에 자동으로 "낮음"으로 바뀌어요.

## 내 컴퓨터에서 먼저 테스트하기

Node.js(18 이상) 설치 후:

```
npm install
npm start
```

- 선생님: `http://localhost:3000/?teacher=teacher1234`
- 학생: `http://localhost:3000` 을 탭 3개 이상으로 열기 (탭마다 다른 대원)
- 전자칠판: `http://localhost:3000/screen.html`

## 알아두면 좋은 점
- 맵은 방 14개로 30명이 흩어져 플레이하기 좋은 크기예요.
- 서버를 재시작하면 진행 중인 게임과 내보내기 목록은 초기화됩니다.
- 학교 와이파이에서 웹소켓이 막히면 자동으로 다른 방식으로 연결되지만, 첫 수업 전에 교실에서 한 번 테스트해 보세요.
